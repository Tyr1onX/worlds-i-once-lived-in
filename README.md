# 我曾生活过的世界

> *worlds i once lived in*

这里保存一些童年与少年时期曾经反复出现、如今只剩下片段和影子的幻想世界。

这不是一个需要主动“回忆完整”的项目，也不要求把它们整理成合理的故事。想起什么，就留下什么。

## 两份长期记录

- [`MEMORIES.md`](./MEMORIES.md)：只保存原始口述。尽量逐字保留，不润色、不修正逻辑、不用后来的记忆填补空白。
- [`REFLECTIONS.md`](./REFLECTIONS.md)：保存从这些口述中产生的理解、联想、共同母题与可能的文学方向。它可以变化，但不能反过来改写原始记忆。

## 约定

1. **原话优先。** 模糊、矛盾、无厘头都可以保留。
2. **只追加，不重构记忆。** 不为了“写得更好”而覆盖以前说过的话。
3. **不强迫回忆。** 偶尔想起一个场景、一件装备、一个人、一句话，再补进去即可。
4. **记忆与解释分离。** `MEMORIES.md` 记录“当时想起了什么”，`REFLECTIONS.md` 记录“现在如何理解它”。
5. **小说不是前提。** 这些内容未来可以成为小说素材，也可以永远只是一份私人世界档案。
